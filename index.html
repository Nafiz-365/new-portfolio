PROJECT / 08 · LIVE

BazarDor — Bangla Market Price Tracker

A Bangla-first essential-goods price tracker for markets across Bangladesh. Real auth system with three sign-in paths — email and password, Google OAuth, and GitHub OAuth — persisting to MongoDB Atlas through BetterAuth's adapter. The product detail page is gated server-side with auth.api.getSession() before the page ever renders, so unauthenticated users are redirected instead of seeing a flash of content. The API layer tries a primary origin and a fallback origin in sequence, so a single provider outage doesn't break the price ticker or product grids. Home risers and fallers are computed on the server via force-dynamic pages, and the entire UI — dates, numbers, and messages — is rendered in Bangla.

Next.js 16React 19TypeScriptTailwind v4BetterAuthMongoDBOAuthServer Components

PROJECT / 09 · IN DEVELOPMENT

News-365 — Bangla News Aggregator

A Bangla-language news reader built almost entirely out of async server components. The home page fetches sections, the marquee fetches headlines, the navbar fetches categories, and the sidebar fetches most-read — four independent requests that render in parallel, and each one fails in isolation. Every request is wrapped in AbortSignal.timeout(10000), and every JSON payload is validated at runtime with hand-written type guards before it reaches a component, so a malformed upstream response can't crash the page. The article body arrives as a deeply nested BlockNote structure and is safely flattened into readable paragraphs with a plain-text fallback.

Next.js 16React 19TypeScriptTailwind v4DaisyUIServer ComponentsAbortController
